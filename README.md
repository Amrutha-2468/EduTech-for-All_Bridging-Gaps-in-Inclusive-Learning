# 🎓 EduTech for All: Bridging Gaps in Inclusive Learning
Inclusive EdTech platform with speech-to-text, text-to-speech, and personalized learning for specially-abled students.

## 📌 Overview

**EduTech for All** is an inclusive educational platform designed to support **specially-abled students** by providing accessible learning resources and assistive technologies. The project focuses on improving accessibility, governance, and inclusivity in education by integrating modern web technologies with accessibility-focused features.

The platform aims to bridge the gap between traditional learning systems and the needs of students with disabilities by offering **adaptive learning tools, personalized learning plans, and accessibility features**.

---

## 🚀 Features

* 📚 Accessible learning resources (Books & Videos)
* 🎤 Speech-to-Text functionality for hearing-impaired users
* 🔊 Text-to-Speech functionality for visually impaired users
* 🧠 Personalized learning plans
* 📝 Interactive quizzes with accessibility options
* 🛒 Accessibility products store with cart & checkout
* 📊 User-friendly and responsive UI
